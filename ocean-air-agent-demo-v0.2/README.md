# 海空跨域无人集群 Agent · 网页 Demo v0.2

这是曜石黑金深海主题的静态网页原型，开箱即可本地查看，无需安装前端依赖或连接网络服务。

## 启动

1. 解压压缩包并进入解压得到的项目文件夹。
2. 在该文件夹中启动本地网页服务：

   macOS / Linux：

   ```bash
   python3 -m http.server 4173 --bind 127.0.0.1
   ```

   Windows：

   ```powershell
   py -m http.server 4173 --bind 127.0.0.1
   ```

3. 在浏览器打开 <http://127.0.0.1:4173/app/>。

结束演示时，在终端按 `Ctrl+C` 停止网页服务。

## 页面功能

- 右上角可重播任务理解、生成航迹与模拟验证过程。
- 可在任务输入框中提交演示文本；可切换地形和航迹显示、展开地图。
- 点击完成卡片查看 Mock 任务报告。
- `assets/h-theme/` 内的海景图片是视觉素材；航迹、边界、标注和仪表由网页代码绘制。

## 演示范围

此版本展示 UI 与本地交互。海域为虚构场景；覆盖率、面积、航程和航点均为示例数据，航迹不是算法规划结果，也不用于真实导航或无人平台控制。

## 文件

- `app/`：网页 HTML、CSS、JavaScript。
- `assets/h-theme/`：网页标识和运行所需海域素材。
- `tests/ui-demo.test.mjs`：使用 Node.js 内置测试运行时的 7 项交互逻辑测试。
- `preview.jpg`：可快速查看界面效果。

运行测试：`node --test tests/ui-demo.test.mjs`。
